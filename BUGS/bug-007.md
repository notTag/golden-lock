# [007] git child PATH omits /opt/homebrew/bin despite it being a vetted git location

- Status: open
- Created: 2026-06-12
- Severity: low
- Bump: patch

## Repro
1. On Apple Silicon where git lives at `/opt/homebrew/bin/git`, run
   `golden-test verify` (non-root) from inside a git repo.
2. Inspect `FindRepoRoot` → `vettedGitPath` (lockfile.go:112-124) and the env
   it sets for the git child (lockfile.go:76).

## Expected
The pinned `PATH` handed to the git child includes the same trusted locations
`vettedGitPath` is willing to select git from.

## Actual
`vettedGitPath` will pick `/opt/homebrew/bin/git`, but the child env pins
`PATH=/usr/bin:/bin:/usr/local/bin`, which omits `/opt/homebrew/bin`. If git
ever needed to exec a helper from its own directory, it would not find it.
`git rev-parse --show-toplevel` spawns no helpers, so this is harmless today.

## Notes
Cosmetic/defensive. Fix: append the directory of the chosen `vettedGitPath` to
the pinned `PATH`, or derive the pinned `PATH` from the vetted-candidate dirs so
the two lists can't drift.
